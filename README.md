# FlumeTV-UI
The management UI for the FlumeTV Stremio IPTV addon — add, edit, and toggle Direct M3U &amp; Xtream Codes sources with named configs, real-time prefetch-status SSE and in-progress log streaming, Stremio manifest URL copy &amp; web-install links, modal auth with session cookies, Slate light/dark theme, i18n, and responsive layout. Pairs with FlumeTV-API.
